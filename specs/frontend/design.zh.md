# Ember Studio

[English](design.md) | 中文

<a id="overview"></a>

## 概览

一套温暖、专注手艺感的设计系统，面向创意项目管理工具。美学将赤陶色的暖意与现代极简融合 —— 柔和的大地色调奠定界面基调，琥珀色点缀把注意力引向操作与进度。为美感与生产力并重的团队而设计。浅色与深色两种模式都经过刻意设计，而非简单反色。整体气质沉静、专注、带一点克制的精致。

<a id="colors"></a>

## 颜色

- **主色**（#C2410C）：赤陶 —— CTA、激活态、链接、焦点环、进度指示器
- **主色悬停**（#9A3412）：深煅赭 —— 主色元素的悬停态
- **强调色**（#F59E0B）：琥珀 —— 通知、徽章、高亮、新增条目指示器
- **中性色**（#78716C）：石灰 —— 弱化文本、占位符、时间戳、元数据
- **背景**（#FAFAF9）：带一丝奶油感的暖白页面背景
- **表面**（#F5F5F4）：卡片、面板、模态框 —— 略暖的灰白
- **抬升表面**（#E7E5E4）：悬停态、选中行、激活标签页
- **主要文本**（#1C1917）：暖调近黑 —— 标题、正文、主要标签
- **次要文本**（#57534E）：暖灰 —— 描述、说明文字、次要信息
- **边框**（#D6D3D1）：暖灰边框 —— 卡片边缘、分隔线、输入框边框
- **成功**（#16A34A）：已完成任务、已批准条目、正向状态
- **警告**（#D97706）：即将到期、需要关注、警示横幅
- **错误**（#DC2626）：逾期、失败、破坏性操作

<a id="typography"></a>

## 排版

- **展示字体**：Playfair Display —— 从 Google Fonts 加载
- **正文字体**：Source Sans 3 —— 从 Google Fonts 加载
- **代码字体**：Fira Code —— 从 Google Fonts 加载

展示与标题文本使用 Playfair Display 粗体字重与紧凑字距（-0.02em）。衬线展示字体传达手艺与刻意感。正文与 UI 文本使用 Source Sans 3 的常规（400）与半粗（600）字重 —— 干净、高度易读的无衬线体。代码块使用 Fira Code 并启用连字。

字号阶梯：展示 64px、标题 48px、节标题 28px、副标题 20px、正文 16px、小号 14px、说明 12px、Overline 11px 大写字距加宽。

<a id="elevation"></a>

## 阴影层级

卡片默认平铺，带 1px 暖色边框（#D6D3D1），悬停时获得柔和阴影（0 4px 16px rgba(28,25,23,0.06)）。激活/选中的卡片获得 2px 赤陶色左边框。主按钮悬停时泛起暖光晕（0 4px 12px rgba(194,65,12,0.25)）。模态框使用更大的阴影（0 24px 48px rgba(28,25,23,0.12)）加背景模糊。导航栏透明并带 backdrop-blur，滚动时出现 1px 底边框。

<a id="components"></a>

## 组件

- **按钮**：主按钮赤陶色（#C2410C）填充配白字，8px 圆角，半粗字重。次按钮透明背景配 1px 石灰边框（#D6D3D1）、暖色文字。幽灵按钮无边框、仅文字颜色。破坏性按钮红底白字。所有按钮 150ms 过渡。尺寸：小（32px 高、12px 内边距）、中（40px、16px）、大（48px、24px）。
- **卡片**：暖白表面（#F5F5F4），1px 边框（#D6D3D1），12px 圆角，16px 内边距。项目卡片带与项目颜色匹配的彩色左条纹（4px）。悬停上浮 2px 并加深阴影。选中卡片带赤陶色左边框。
- **输入框**：1px 边框（#D6D3D1），表面背景（#F5F5F4），8px 圆角，12px 内边距，16px 字号。聚焦：边框转赤陶色并带暖色光环（0 0 0 3px rgba(194,65,12,0.12)）。错误：边框转红。标签为输入框上方 14px 半粗。
- **Chips**：药丸形（9999px 圆角）。分类 chips：stone-100 背景、stone-600 文字、6px/14px 内边距。激活：赤陶色背景、白字。优先级 chips 使用语义色配同色系文字。
- **进度条**：4px 高、全圆角、stone-200 轨道、赤陶色填充。填充带 300ms ease 过渡动画。上方小字百分比标签。
- **头像**：圆形（9999px 圆角），默认 32px。团队展示时以 -8px 重叠堆叠。边框：2px 实线表面色以分隔。
- **标签页**：水平下划线样式。未激活：石灰文字、无下划线。激活：赤陶色文字配 2px 底边框。悬停：暖灰背景。
- **导航**：侧边栏布局，256px 宽。暖白背景配 1px 右边框。顶部为 logo 与工作区名。带可折叠区与折角开关。激活项：3px 赤陶色左侧强调条配暖色浅底。

<a id="spacing"></a>

## 间距

- 基本单位：4px
- 阶梯：4、8、12、16、20、24、32、40、48、64、80px
- 组件内边距：小 8x12、中 12x16、大 16x24
- 节间距：移动端 24px、平板 32px、桌面 48px
- 容器最大宽度：1200px，左右 24px 内边距
- 卡片网格间距：移动端 16px、桌面 24px

<a id="border-radius"></a>

## 圆角

- 4px：行内代码、小徽章
- 8px：按钮、输入框、下拉框
- 12px：卡片、面板、模态框、弹出层
- 9999px：头像、chips、药丸、进度条

<a id="dos-and-donts"></a>

## 该做与不该做

- 该做：赤陶色（#C2410C）只用于可交互元素与激活态 —— 绝不作装饰
- 该做：始终遵守 4px 间距网格
- 该做：标题用 Playfair Display、正文用 Source Sans 3 —— 衬线/无衬线的对比是这套设计的签名
- 该做：保持暖调一致 —— 避免冷灰或偏蓝的中性色
- 该做：琥珀强调色克制地只用于吸引注意力的元素
- 不该做：单一屏幕使用超过两种字重（常规 + 半粗）
- 不该做：混用圆角值 —— 按钮用 8px、卡片用 12px
- 不该做：使用纯黑或纯白 —— 始终使用暖色系的色板值
- 不该做：添加装饰性元素 —— 暖意来自色板而非纹饰
- 不该做：同一节放置多个赤陶色按钮 —— 每个视图一个主 CTA
