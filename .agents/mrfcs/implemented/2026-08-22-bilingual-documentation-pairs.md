# MRFC: Bilingual documentation pairs

Status: implemented

English | [中文](2026-08-22-bilingual-documentation-pairs.zh.md)

## Problem

The corpus serves readers in two languages — the maintainer works in Chinese, and the first record pair exists on that instruction — but nothing governs which language a page is written in. `specs/` was single-language per file in English, Chinese, or a mid-sentence mix (`auth.md`, `api-design.md`, both `i18n` specs, and `e2e/HANDBOOK.md` Chinese-native; a dozen-odd others mixed), `backend/docs/API_SPECIFICATION.md` was a stale Chinese page hiding behind the generated-Swagger exemptions, and the root README pair predated the naming the MRFC tree established (`README_zh.md` against `.zh.md`). A reader got half the corpus natively and half not at all, and which half depended on the directory. No page kept step with a counterpart in the other language because no page had one: the bilingual mechanism that existed — optional `.zh.md` twins, exercised by the tree's README and exactly one record — made single-language files the default, so `PRINCIPLES.md`, the guides, and every historical record were English-only while half the specs were Chinese-only or mixed. The [2026-08-21 verdict](./2026-08-21-documentation-gates-and-mrfc-system.md) had deferred the reference project's bilingual machinery until a trigger signal appeared; serving both language communities across the whole corpus was that signal.

## Decision

**Equal-authority pairs, one naming.** Every documentation file except agent instructions ships as a pair: `foo.md` in English beside `foo.zh.md` in Chinese, same directory, no locale infix on the English side — `README_zh.md` was renamed to `README.zh.md` to match the convention the MRFC tree, the first record twin, and the format gate's filename regex already share. Both languages carry equal authority: either side may be authored or edited first, the edited side is the source for that change, and the twin follows in the same change as a minimal patch — never a wholesale re-translation; where a pair substantively disagrees, the side that is wrong is fixed, and neither language wins by default. Scope is the documentation corpus — root README, `PRINCIPLES.md`, `docs/`, `specs/` including the index, `.agents/mrfcs/` including every historical record, `e2e/HANDBOOK.md` — with exemptions in an exclusions-only manifest, [`scripts/doc_languages.manifest.json`](../../../scripts/doc_languages.manifest.json): agent instructions (every `AGENTS.md`/`CLAUDE.md`/`SKILL.md` and the skills mirror), the ledgers `CHANGELOG.md` and `KNOWN_ISSUES.md` (narrated history, per-entry translation duty, no reader value), `scripts/loadtest/` point-in-time reports, generated Swagger, and `.zcode/`. `backend/docs/API_SPECIFICATION.md` was deleted outright: a stale Chinese duplicate of [`specs/backend/api-schema.md`](../../../specs/backend/api-schema.md) — the endpoint reference's single home — contradicting it on basic facts (base path `/api` against `/api/v1`).

**One gate, five checks.** [`scripts/verify_doc_pairs.py`](../../../scripts/verify_doc_pairs.py) — stdlib Python over `doclib`, staged-restrictable like its siblings, expanding a staged file to its whole pair — enforces: pair completeness in both directions (every in-scope `.md` has its `.zh.md`; no `.zh.md` is an orphan); a language switcher in each side's header region linking its twin, the one sanctioned cross-locale link; link locale (a relative link into the corpus from a `.zh.md` targets the `.zh.md` variant, from a `.md` the `.md`; targets outside the corpus keep their path); structural parity in its simple form — identical heading-depth sequences and byte-identical fenced code blocks, comments included, because examples are not translated; and language purity — no CJK in the prose of an in-scope `.md`, with per-file manifest exemptions for pages whose subject legitimately requires CJK and no reverse check on `.zh.md`, which legitimately carries English terms. It runs as part of [`doc_sync.py`](../../../scripts/doc_sync.py), so the prek staged run and the CI full run enforce it with no new wiring; the staged run tolerates a not-yet-written `.zh.md` link target, which let parallel translation waves land without cross-wave link races while CI's strict full run owns the end state.

**Gates and homes adapt.** [`specs/index.md`](../../../specs/index.md) pairs into its zh twin with translated row summaries, and [`verify_specs_index.py`](../../../scripts/verify_specs_index.py) checks one row per pair — the stem with both language suffixes stripped — in each index, skipping the indexes' own switcher link. The [MRFC README](../README.md) states the mandatory contract — every record is a pair, [`verify_mrfc_format.py`](../../../scripts/verify_mrfc_format.py) checks both skeletons with machine tokens and section headings in English, and ASCII anchors beside Chinese headings keep fragment links locale-independent. The `verify_md_*.py` patterns swapped `README_zh.md` for `README.zh.md` (directory globs already covered `.zh.md` siblings); the docs workflow's path filter follows the manifest. The contract itself is rule 7 in [`docs/AGENTS.md`](../../../docs/AGENTS.md): equal authority, the switcher, link locale, code-fence identity, ASCII anchors, half-width spaces between CJK and Latin, full-width punctuation, and the seed terminology carried inline — the 600-word ceiling favored the inline list over a table, and a standalone terminology file stays signal-gated — plus the note that document `.zh` corresponds to the application's `zh-Hans` locale (the app's own i18n untouched). The root `AGENTS.md` points at rule 7 in one line; the `doc-standards`, `writing-mrfcs`, and `commit` skills carry the workflow.

**The corpus normalized in one change-set.** A per-file language audit sorted every in-scope page into English-only (a twin written), Chinese-native (English content written into the `.md`, the Chinese text cleaned into the `.zh.md`), or mixed (split properly into both) — forty-nine pairs over roughly a hundred files, landed as tiered commits (mechanism, core pairs, the MRFC back-catalogue, then `specs/` in waves), each staging complete pairs. Historical records translated too: no two-class corpus, so the Chinese reader keeps the decision history. `PRINCIPLES.md` pairs as well; its scheduled deletion removes the pair with it. Normalization deliberately corrected stale facts it met — the `pkg/apierr` path, delivery-queue UI strings that no longer matched the locale files, frontend build/i18n fences updated to the current code — each recorded in its tier's commit.

**The mechanism grows on signals, not speculatively.** Declined for now, each with the trigger that would revive it: per-pair blob-hash sidecars and freshness records (one-sided prose edits repeatedly slipping through review); a PR-level co-change diff gate (single-sided pair incidents); full structural signatures over tables and lists (structural drift); a standalone terminology file with forbidden renderings (inconsistent term translations surfacing in review); translation briefings, a dedicated translation skill, or an MT pipeline (whole-file translation becoming routine); merge drivers for pairing metadata (reference-project scale). The reference project's machinery — roughly 5,300 lines of TypeScript serving about 1,150 pairs — is the recorded ceiling of where this road leads, not the starting point.

## Alternatives considered

**Port the reference project's bilingual machinery wholesale** — `.md` + `.zh.md` + `.i18n.yaml` blob-hash consistency records, structural signatures over headings, tables, lists, and links, a translation-briefing generator, a sealed archive, and a git merge driver. It lost: about 4.6 lines of tooling per pair against a corpus of fifty, a sidecar re-record tax on every documentation edit, and a dependency shape (Node toolchain, mdast) the Python-stdlib gate suite deliberately avoids. This record executes the 2026-08-21 trigger clause as designed; it does not reverse the verdict.

**Rules without a gate.** Prose in `docs/AGENTS.md` asking authors to keep pairs in step. It lost: undisciplined drift was the exact failure the 2026-08-21 gates exist for, and every rule in the standard names the gate that enforces it — a bilingual rule without machinery re-creates that failure in two languages.

**Locale directories (`en/` and `zh/` subtrees).** It lost: side-by-side pairs keep the twin in the same diff and the same review, and let a link switch locale by suffix; directories split each page from its own maintenance and turn the link graph into two trees to keep honest.

**English primary, Chinese as translation.** It lost: the requirement is equal authority, and the corpus already disagreed with primacy — several pages were Chinese-native because Chinese is the maintainer's stronger language; a primary rule would demote the side more likely to be authored first and re-file existing Chinese pages as derivatives of translations that did not exist.

**Keep the `README_zh.md` naming.** It lost: `.zh.md` is already the established convention — the tree README, the first record twin, and the format gate's filename regex all use it; two spellings for one idea is its own drift.

**Grandfather the back-catalogue** — historical records and `PRINCIPLES.md` stay single-language, new files pair. It lost: a two-class corpus whose Chinese half loses the decision history for a bounded one-time cost, and an exemption class that would outlive its justification as records accumulate.

## Consequences

The full corpus runs green under all seven gates: 49 pairs verified for completeness, switchers, link locale, structural parity, and purity; 30 spec pairs listed in both indexes; 24 MRFC files following the format. The staged gate was exercised as designed — deleting a heading from one side failed the pair check and the drill was reverted — while a one-sided prose edit stays beyond this tier's machinery, named as the first signal-gated upgrade. Implementation surfaced two gate truths fixed with the change: `verify_specs_index.py` stems must strip both language suffixes or the two indexes never agree, and an index's language switcher must not count as a spec row. Normalization also fixed stale facts in passing (`pkg/apierr` → `internal/apierr`, delivery-queue locale strings, frontend build/i18n fences) and flagged one follow-up outside this decision's scope: `specs/frontend/testing.md` carries e2e facts that do not match the repo (a `frontend/tests/` directory and `pnpm test:e2e` script that do not exist), mirrored faithfully into both languages pending a content fix on the pair. Accepted costs: no gate checks meaning — structural parity proves shape, not substance, and a sloppy twin passes green, so review carries semantics; the terminology seed sits inline in rule 7 after the 600-word ceiling rejected a table (`docs/AGENTS.md` lands at 575 words — condense-first held, no ceiling raise); every future documentation change carries the bilingual duty, proportionate to a corpus an order of magnitude smaller than the reference's; and the ~100-file normalization was reviewed by spot-check plus gates, the accepted mode for translation at this scale.
